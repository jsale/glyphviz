# Moby "Go" — Audio Animation Example

64-band spectral array driven by Moby's *Go*.

**The source recording is not included** (commercial copyright — it is not
ours to redistribute). All generated files are committed, so the animation
plays fine; to also hear the music in sync, supply the audio yourself:

1. Convert your copy of the song to mono 16-bit PCM WAV.
2. Save it as `media/mobygo1_mono.wav` (the name
   `Moby_Go_Example_gv_audio.txt` points at).

GlyphViz picks it up automatically: **File > Open Node CSV** →
`Moby_Go_Example_gv_node.csv`, then press Play in the Channels panel.
