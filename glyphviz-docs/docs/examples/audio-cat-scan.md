# Cat Scan — Audio Animation

A 64-band spectral array driven by Tangerine Dream's *Cat Scan*: each log-spaced frequency band is a three-level hyperglyph whose altitude channels follow the band's power through the track.

![Cat Scan — Audio Animation loaded in GlyphViz](../assets/examples/audio-cat-scan.png)

*The commercial source recording is not redistributed; all generated animation files are included.*

**Try it:** download this example below (or [the full examples set](../getting-started/installation.md#example-scenes)), then open `Audio_Animation_Example/Cat_Scan_Example/Cat_Scan_Example_gv_node.csv` — or just drag its folder onto the GlyphViz window. Press **Space** to start the animation.
