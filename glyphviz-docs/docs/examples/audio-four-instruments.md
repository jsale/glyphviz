# Four Instruments in C Major

The audio-Channels pipeline run on a four-instrument piece in C major — watch different instruments light up different regions of the 64-band spectral array.

![Four Instruments in C Major loaded in GlyphViz](../assets/examples/audio-four-instruments.png)

**Try it:** [download the examples set](../getting-started/installation.md#example-scenes), then open `Audio_Animation_Example/Four_Instruments_C_Major_Example/Four_Instruments_C_Major_Example_gv_node.csv` — or just drag its folder onto the GlyphViz window. Press **Space** to start the animation.
