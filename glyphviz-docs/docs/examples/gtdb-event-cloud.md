# GTD — Event Cloud

No aggregation: every incident in the database (~205,000) is one octahedron placed by longitude and latitude, with altitude as date and color as attack type — a half-century of events as a single cloud, and a deliberately large scene.

![GTD — Event Cloud loaded in GlyphViz](../assets/examples/gtdb-event-cloud.png)

*Data: Global Terrorism Database (START, University of Maryland), 1970–2020.*

**Try it:** [download the examples set](../getting-started/installation.md#example-scenes), then open `Global_Terrorism_Example/Event_Cloud/EventCloud_gv_node.csv` — or just drag its folder onto the GlyphViz window.
