# Tutorials

A guided, hands-on path from your first rendered scene through hierarchy and topology/geometry choices. Work through them in order — each builds on the last. Unlike the [Quickstart](../getting-started/quickstart.md) and the [Guided Tour](../getting-started/guided-tour.md), which both work through the GUI, these tutorials have you hand-author the underlying `gv_node.csv` yourself — the format every real GlyphViz scene is built from, whatever generates it.

1. **[Your First Scene](01-first-scene.md)** — hand-type a minimal node CSV, render it, give it a child, and close the edit → save → watch-it-update loop.
2. **[Tags & Hierarchy](02-tags-hierarchy.md)** — label your nodes, branch the hierarchy into siblings and a grandchild, and learn the difference between a scene-wide tag toggle and pinning a label on.
3. **[Topology & Geometry Choices](03-topology-geometry.md)** — flip the same hierarchy through Torus, Sphere, and Pin topologies without touching geometry, and see exactly what carries over and what breaks.
