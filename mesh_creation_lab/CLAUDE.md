- **Mesh Creation Lab (2026-09-17)** — `mesh_creation_lab/`, a lab beside `ai_observatory/` and deliberately NOT part of `examples/` (Jeff's call: these are capability demos, not gallery scenes, so they stay out of the gallery, the per-example zips and `GlyphViz_Examples.zip`). `mesh_creation_lab/meshkit.py` (Qt-free: box/prism/loft/revolve/tube/surface, writing OBJ with UVs) and `texkit.py` (seamless tiling textures — facade, brick, asphalt, bark, hull plating, greeble, foliage, metal), plus `gvscene.py`'s `SceneBuilder`. Three things they encode that a generator WILL otherwise get wrong: **(a)** the loader re-centres and normalizes every file on its OWN bbox, so a multi-part model's parts arrive in different coordinate systems — `Model.assembly()` returns the per-part offset/scale that undo it, hung off one hidden **rig** node (verified exact against `scene.node_world_matrix`: child world pos = rig_pos + R·(translate × rig_scale), drawn scale = scale × rig_scale). **(b)** a textured node's colour **multiplies** its texture (GL_MODULATE), so textured meshes take near-white TINTS — the first tree draft used real bark/leaf colours and rendered the grove black. **(c)** `SceneBuilder.rig()` relocates a label to the first visible child, because **a hidden node draws nothing and the tag pass only labels what it draws**. Also: `NODE_TYPE_GLYPH = 5` is a convention, not a named constant — writing `type=0` puts a node in `NON_VISUAL_TYPES` and the whole scene renders empty. Scenes: `Tree/` (instancing), `Building/` (UV-textured facades — windows are texels; 202 m tower in 216 tris), `City/` (74 buildings + 64 cars from 16 files; `uv_world` keeps window size constant across massings; an exhibit showing non-uniform rig scale stretching facade UVs), `Whale/` (smooth lofting from a lines plan — its first table was 2x too wide and rendered a balloon), `Jet/` (6 materials; built nose-along-+Y so rig rotate_z IS heading), `Starship/` (1,600 power-law greebles planted on the real hull surface — greeble SIZE RANGE matters more than count, the first pass at 5.5% of ship length ate the silhouette; `GEO_SPHERE_INTERIOR` starfield). Each folder carries its generator + README. **(d) Negating an angle is NOT a mirror**: placing a left/right pair with `rot_z(-90 * side)` rotates the left copy 180 deg about the vertical instead of reflecting it, so a swept wing sweeps FORWARD on one side and an aerofoil trails its round leading edge — a pinwheel that is rotationally, not mirror, symmetric and looks merely 'a bit off' from most angles. Both the jet and the whale shipped with it; Jeff caught it from top-down screenshots. `meshkit.mirror_pair()` places the +X side and derives the other, and `Mesh.extend` reverses triangle winding under any negative-determinant matrix (a reflection flips face normals, which the crease pass reads from winding).
